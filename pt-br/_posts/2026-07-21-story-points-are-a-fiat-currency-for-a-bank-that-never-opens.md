## O Auditor De Story Point

Depois de 47 anos auditando rodadas de poker na mão, eu automatizei. Esse script lê as estimativas de uma sprint e produz a única avaliação honesta: uma recomendação de queimar a moeda e reabrir o banco num ramo diferente.

```python
def auditar_story_points(sprint):
    """
    O único auditor honesto de story point.
    Um story point é um número escrito num cartão
    pra que uma data não precise ser escrita num cartão,
    por um time que não vai se comprometer,
    pra relatar produtividade
    que não é produtividade.
    """
    report = {}

    for ticket in sprint.tickets():
        # Um ticket estimado antes de ser lido é uma leitura de Ouija.
        if not ticket.foi_lido_antes_de_estimar:
            report[ticket.id] = "ESTIMADO_DO_TITULO_ISSO_E_DIVINACAO"
            continue

        # Um ticket cuja estimativa é igual à fatia média do velocity
        # do time é um número escolhido pra preencher, não pra medir.
        if abs(ticket.pontos - sprint.fatia_media) <= 1:
            report[ticket.id] = "PREENCHIDO_PRA_CAPACIDADE_NAO_ESTIMADO"
            continue

        # Um spike estimado em pontos é fictício puro: respaldado por nada.
        if ticket.e_spike:
            report[ticket.id] = "ATIVO_FIAT_VALOR_E_O_QUE_O_TIME_DIZ_QUE_E"
            continue

        # Um ticket re-estimado pra cima depois de carregado é inflação, não escopo novo.
        if ticket.contagem_carregados > 0 and ticket.pontos > ticket.pontos_originais:
            report[ticket.id] = "INFLACAO_RELATADA_COMO_MUDANCA_DE_ESCOPO"
            continue

        # Um ticket marcado 'done' no mesmo dia que arrastado é lavagem.
        if ticket.arrastado_done_mesmo_dia_do_fechamento:
            report[ticket.id] = "ARRASTOU_NAO_FEZ_VELOCITY_E_LAVAGEM"
            continue

        # O padrão honesto: o número é o que o time precisava que fosse.
        report[ticket.id] = "APROVADO_PORQUE_O_BANCO_EQUILIBRA"

    return report

# Output de auditar um ano de sprints em 2026:

# ATIVO_FIAT_VALOR_E_O_QUE_O_TIME_DIZ_QUE_E: 97
# INFLACAO_RELATADA_COMO_MUDANCA_DE_ESCOPO: 184
# ARRASTOU_NAO_FEZ_VELOCITY_E_LAVAGEM: 61
# APROVADO_PORQUE_O_BANCO_EQUILIBRA: 11
# Total de pontos emitidos: 9.073
# Total de pontos queimados: 9.073
# Diferença entre emitidos e queimados: 0
# Diferença entre pontos e horas reais trabalhadas: imensurável, não medida, e o banco prefere assim
```
